# Anatomy model attribution

Vide ships the complete **Z-Anatomy** human musculoskeletal model for the 3D viewport.

## Model

| Field | Value |
| --- | --- |
| File | `body.glb` |
| Contents | Full body with all bones and muscles (434 deduplicated meshes) |
| Original project | [Hello-Tebatso/body-anatomy-3d-viewer](https://github.com/Hello-Tebatso/body-anatomy-3d-viewer) |
| Upstream atlas | [Z-Anatomy](https://www.z-anatomy.com/) |
| Original dataset | [BodyParts3D](https://lifesciencedb.jp/bp3d/) |
